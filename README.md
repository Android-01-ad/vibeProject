# BibeProject 로직 정리

이 프로젝트는 Unity 기반의 로그라이크 덱 전투 구조를 담고 있습니다. 아래 파일들은 각기 역할이 나뉘어 있으며, 게임 흐름 관리 / 카드 덱 관리 / 플레이어 상태 / 필드 오브젝트 처리를 분리해 운영하고 있습니다.

## 주요 스크립트

### 1. `Assets/script/RoguelikeGameManager.cs`
게임의 전체 흐름을 관리하는 메인 매니저입니다.

- 게임 시작, 런 초기화
- 전투 루프와 적 턴 처리
- 스테이지 전환 (전투 / 보상 / 보스)
- 보상 선택 처리
- 승리/패배 판정
- 개발자 모드 입력 처리

핵심 역할:
- 스테이지 흐름 제어
- 보상 카드 선택 관리
- 현재 상태를 외부에 제공

### 2. `Assets/script/DeckManager.cs`
카드 덱 전용 로직을 담당하는 전담 관리자입니다.

- 보유 덱 관리
- 드로우 덱 관리
- 버리기 덱 관리
- 카드 추가 및 중복 카드 강화
- 드로우 덱 소진 시 버리기 덱에서 재셔플

핵심 역할:
- 카드 수집/사용/셔플 로직 분리
- GameManager가 덱 규칙을 직접 처리하지 않도록 분리

### 3. `Assets/script/PlayerCharacter.cs`
플레이어 캐릭터의 전투 상태와 행동을 담당합니다.

- 클래스 선택 및 전직
- 체력 관리
- 공격력 계산
- 카드 사용 시 필드 오브젝트 처리
- 적에게 공격

핵심 역할:
- 플레이어 상태 관리
- 전투 기능 제공
- 오브젝트 상호작용 처리

### 4. `Assets/script/CardDefinition.cs`
카드 하나의 기본 데이터 모델입니다.

- 카드 이름
- 설명
- 강화 단계
- 강화된 표시 이름
- 카드 힘(Power) 계산

핵심 역할:
- 카드 자체의 데이터 저장
- 중복 획득 시 강화 상태 반영

### 5. `Assets/script/CardCatalog.cs`
CSV 기반 카드 목록을 읽어오는 유틸리티입니다.

- 카드 데이터 로드
- CSV 파싱
- 카드 인스턴스 생성

핵심 역할:
- 카드 풀 생성
- 게임 시작 시 카드 데이터 초기화

### 6. `Assets/script/DeckScreenController.cs`
덱 UI 화면을 제어하는 컨트롤러입니다.

- 보유 덱 표시
- 카드 리스트 렌더링
- 덱 화면 열기/닫기

핵심 역할:
- UI 표시 담당

### 7. `Assets/script/EnemyCharacter.cs`
적 캐릭터의 상태와 행동을 관리합니다.

- 적 이름
- 공격력
- 체력 및 사망 체크
- 플레이어 공격에 반응

핵심 역할:
- 적 전투 동작

### 8. `Assets/script/BossCharacter.cs`
보스 전용 캐릭터입니다.

- 보스 이름
- 보스 사망 시 이벤트 전달
- 전투에서의 승리 판정 트리거

핵심 역할:
- 보스 처치 감지

### 9. `Assets/script/BossStageIntro.cs`
보스 스테이지 입장 연출용 스크립트입니다.

- 보스 이름 표시
- 애니메이터 트리거 실행
- 파티클/사운드/카메라 연출
- 인트로 종료 콜백

핵심 역할:
- 보스 등장 연출 담당

### 10. `Assets/script/ObstacleObject.cs`
전투용 장애물 오브젝트입니다.

- 전투 카드 사용 시 파괴
- 파괴 애니메이션 재생
- 파괴 이펙트 실행
- 일정 시간 후 제거

핵심 역할:
- 시야/장애물 제거 오브젝트

### 11. `Assets/script/TreasureChestObject.cs`
보물 상자 오브젝트입니다.

- 탐험 카드 사용 시 열림
- 오픈 애니메이션 재생
- 오픈 이펙트 재생
- 일정 시간 후 제거

핵심 역할:
- 보상 상자 오브젝트 처리

## 설계 흐름

1. `RoguelikeGameManager`가 스테이지와 전투 흐름을 제어합니다.
2. 보상 카드 선택 시 `DeckManager`에 카드 추가를 위임합니다.
3. `PlayerCharacter`는 전투와 필드 오브젝트 상호작용을 처리합니다.
4. 장애물/상자는 각각 전투 카드와 탐험 카드로만 처리됩니다.
5. 보스 / 적 / 덱 / UI는 역할별로 파일이 분리되어 있습니다.

## 폴더 구조 요약

- `Assets/script/` : 게임 로직 전반
- `Assets/StreamingAssets/` : CSV 카드 데이터 등 외부 데이터
- `Assets/` : Unity 씬, 프리팹, 리소스 등

## 주의사항

- 새 스크립트를 추가하면 Unity 프로젝트에서 다시 컴파일됩니다.
- 새로 추가한 오브젝트에는 `Animator`, `ParticleSystem` 연결이 필요할 수 있습니다.
- 보스/장애물/상자 등에 애니메이션 트리거 이름이 실제 Animator 상태와 일치해야 합니다.
